# 데코 요소(스니펫) 카탈로그 & 구현 계획

발표 슬라이드에서 자주 쓰이는 "데코 요소(스니펫)" 모음. 각 항목을 **사용자 시나리오 + 디자인**으로
구체화하여 하나씩 구현한다. (테마 색과 연동되면 더 좋음)

상태 표기: ⬜ 미착수 · 🟡 설계중 · 🔧 구현중 · ✅ 완료

---

## A. 라벨·뱃지 (작은 강조)
| 상태 | 요소 | 데코 특징 | 사용 상황 |
|---|---|---|---|
| ✅ | **필(pill) 라벨** | 라운드 배경 + 작은 대문자 텍스트 | 섹션 태그, 카테고리, 상태(NEW·BETA) |
| ✅ | **숫자 뱃지** | 원형 배경색 + 그림자 + 숫자 | 단계 번호, 순위, 리스트 마커 |
| ✅ | **상태 칩** | 점(●) + 텍스트, 색으로 의미 | 진행중/완료/지연, 범례 |
| ✅ | **키캡** | 입체 테두리 + 모노 글자 | 단축키 표기(⌘K, Ctrl+S) |
| ✅ | **해시 태그/칩** | 옅은 배경 + #키워드 | 키워드, 분류 |

## 우선 구현 후보 (핵심 8)
필 라벨 · 숫자 뱃지 · 콜아웃 박스 · 풀쿼트 · 좌측바 인용/소제목 · 코드블록(맥터미널) · KPI 카드 · 단계 카드

## 구현 접근 (공통)
- **스니펫 레지스트리**(예: `src/core/snippets.js`): 각 스니펫이 `build(cs, theme)` → FlatElement 배열(또는 단일) 반환. 단일 요소형(필/뱃지)과 복합형(단계카드=뱃지+텍스트 그룹)을 모두 지원.
- **삽입 경로**: 컨텍스트 메뉴/요소 추가에 "스니펫" 서브메뉴 또는 전용 패널. 캔버스 중앙(또는 클릭 위치)에 삽입, 새 id, 선택 상태로.
- **테마 연동**: 가능하면 현재 테마 색/강조색 사용.
- **복합 스니펫은 그룹**(groupId)으로 묶어 이동/삭제가 한 덩어리로.
- 각 스니펫 구현 단위: **사용자 시나리오 → 디자인(치수/스타일/테마매핑) → 구현 → 테스트 → 브라우저 확인 → 머지**.

## 진행 로그
- (작성) 카탈로그 정리 + 구현 계획 수립.
- 스니펫 인프라 구축(`core/snippets.js`, EditToolbar "스니펫" 드롭다운, 테마 accent 연동) + **필 라벨·숫자 뱃지** 구현.
- 라운드 핸들이 작은/원형 요소 이동을 가로채는 문제 수정(inset 상한 + 숨김 조건).
- **콜아웃 박스 4종(팁/주의/정보/성공)** 구현(좌측 컬러바 + 옅은 배경 + 아이콘).
- **인용 2종**: 풀쿼트(큰 따옴표), 좌측바 인용/소제목(테마 accent 바).
- **KPI 카드**: 카드 배경 + 큰 숫자(accent) + 라벨 + 추세 — 첫 복합(그룹) 스니펫.
- **단계 카드(가로/세로)**: 숫자 뱃지 + 제목 + 설명(테마 역할색). textSpec 가로정렬(align) 보정.
- **코드 블록(맥 터미널)**: 다크 윈도우 + 3색 점 + 모노스페이스 코드(편집 가능). 신택스 하이라이트는 후속.
- **프로그레스 바**: 트랙 + 채움(accent) + % 라벨. (링/원형은 후속)
- **간단 묶음**: 체크리스트 항목(✓), 상태 칩(●), 키캡(⌘K), 해시 칩(#). textSpec에 rich/border/폰트/패딩 옵션 추가.
