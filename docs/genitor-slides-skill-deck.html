GENITOR-SLIDES SKILL
Genitor 슬라이드
HTML 작성 규약
Claude가 만든 슬라이드를 Genitor(float-editor)가 텍스트·도형·이미지로
그대로 읽어들이도록 만드는 방법
position:absolute · px 좌표 · .slide.active · 단일 자립형 HTML
WHY THIS FORMAT
왜 이 형식 그대로 써야 하나
  • Genitor는 HTML을 iframe에 렌더한 뒤 각 요소의 computed geometry를 읽어 텍스트·도형·이미지로 변환합니다.
  • 임의의 웹페이지 HTML도 열리지만, flexbox 수축·반응형 단위·JS 레이아웃 때문에 배치가 어긋날 수 있습니다.
  • 가장 확실한 방법은 Genitor가 스스로 내보내는 포맷과 똑같이 쓰는 것 — 고정 캔버스 위에 position:absolute로 배치한 인라인 스타일 div들입니다.
핵심 원칙
형식(form)은
고정, 스타일(style)은
매번 새로.
색·폰트·레이아웃은 주제마다 새로 디자인한다
HANDOFF
슬라이드를 Genitor로 가져가는 4가지 방법
1
붙여넣기
HTML 소스 전체를 복사해 Genitor 캔버스에서 Ctrl/Cmd+V. 온전한 <!DOCTYPE html> 문서일 때만 덱 가져오기로 인식합니다.
2
드래그 & 드롭
.html 파일을 Genitor 캔버스 위에 그대로 떨어뜨립니다.
3
파일 열기
File 메뉴 ▸ "HTML 열기"로 파일을 직접 불러옵니다.
4
URL 임포트 링크
HTML을 encodeURIComponent로 인코딩해 앱주소#import=... 링크로 전달. 파일 저장이 어려운 환경(Claude Desktop 등)에 유용하며, 로드 시 자동 디코드됩니다.
THE SCAFFOLD
정본 스캐폴드
이 골격을 그대로 사용한다 — 형식은 항상 고정
body { width:1920px; height:1080px; background:#0f172a; }
.slide { position:absolute; inset:0; display:none; }
.slide.active { display:block; }

<div class="slide active"
    style="width:1920px;height:1080px;">
  <!-- 요소들: position:absolute -->
</div>

// 다음 장은 .slide 를 그대로 이어 붙인다
// (첫 장에만 active, 나머지는 없음)
핵심 규칙
  • 캔버스 기본값 1920×1080 (16:9)
  • 슬라이드마다 .slide, 첫 장만 active
  • 요소는 모두 .slide 안에서
    position:absolute + px 좌표
  • box-sizing:border-box 전역 적용
  • 내비/스크립트 없이도 Genitor가
    장을 자동으로 페이지로 인식
ELEMENT RECIPES
요소 레시피 — 6가지 패턴
.slide 의 직계 자식 div 하나하나가 곧 하나의 편집 요소가 됩니다
TEXT
제목 / 본문 텍스트
div에 텍스트를 직접 넣고 폰트·크기·색·정렬을 인라인 스타일로 지정합니다.
SHAPE
색 박스 / 카드
텍스트가 없는 div는 배경·테두리·그림자를 가진 도형으로 추출됩니다.
CARD · 1 LINE
카드 + 텍스트(병합)
배경 있는 div 안에 텍스트 한 줄만 있으면 하나의 편집 가능한 텍스트 요소로 합쳐집니다.
CARD · MULTI-LINE
여러 줄 카드
카드는 텍스트 없는 도형으로 두고, 라벨·제목·수치·본문을 각각 독립된 절대 위치 텍스트로 쌓습니다.
RICH TEXT / LIST
강조 & 글머리 목록
strong·em·span·br과 ul/li 마커(•)가 그대로 보존됩니다.
MEDIA
이미지 / 영상
래퍼 div로 감싸 img/video를 object-fit으로 채웁니다. 장식은 래퍼가 아닌 미디어 태그에 직접 줍니다.
THE #1 GOTCHA
미디어를 도형이 덮지 않게 하라
Genitor는 클릭 시 최상위 요소를 선택합니다 — 래퍼에 배경/테두리를 주면 그 도형이 미디어를 가로챕니다
✕ 피할 것
<div style="background:#000;
  border-radius:16px">
  <img src="photo.jpg">
</div>
// 래퍼가 도형으로 추출 → 이미지를 덮음
래퍼 div에 배경·테두리·그림자를 주면 래퍼가 도형으로 추출되어 이미지를 덮습니다. 클릭해도 이미지 대신 도형이 선택되고, 이미지 AI 기능도 뜨지 않습니다.
✓ 이렇게
<div style="overflow:hidden;
  border-radius:16px">
  <img style="border-radius:16px"
     src="photo.jpg">
</div>
래퍼는 overflow·border-radius만 갖게 하고, 배경·테두리·그림자는 img/video에 직접 줍니다. 오버레이도 전체가 아닌 하단 스트립 등 부분만 덮습니다.
AVOID THESE
추출이 망가지는 패턴 8가지
아래 패턴은 피하고, 앞선 절의 대안 레시피를 쓴다
  • flex 카드 안에 자식 여러 개 — strong·span·br이 각각 flex item이 되어 가로로 늘어서고 줄바꿈이 깨집니다.
  • JS 레이아웃 / canvas·WebGL — 그려진 내용은 추출되지 않습니다.
  • 반응형 단위(vw·vh·%·clamp) — 폭과 줄바꿈이 렌더링 환경마다 달라집니다.
  • opacity:0 으로 내용 숨기기 — 숨김 처리되어 그대로 사라집니다.
  • position:fixed / onclick 요소 — 내비게이션으로 간주되어 슬라이드 콘텐츠에서 제외됩니다.
  • skew·3D 등 복합 transform — scale만 반영되고 나머지는 사라집니다.
  • ::before content, input placeholder — 추출되지 않는 텍스트입니다.
  • 이미지/영상 위 전면 오버레이 — 최상위 도형이 선택되어 미디어를 고를 수 없습니다.
VERIFY BEFORE HANDOFF
내보내기 전, 반드시 검증한다
scripts/verify_deck.py가 렌더링을 기반으로 4가지 문제를 잡아준다
FLEX+children
자식 요소를 가진 flex 컨테이너 — 가로로 늘어서는 치명적 패턴을 감지
WRAP
선언한 <br> 수보다 실제 렌더된 줄 수가 많은 요소 — 의도치 않은 줄바꿈 감지
OVERFLOW
scrollHeight가 지정한 height를 넘는 요소 감지
OUTSIDE
캔버스(1920×1080) 밖으로 나간 요소 감지
$ pip install playwright --break-system-packages
$ playwright install chromium

$ python3 scripts/verify_deck.py deck.html
→ 문제 없으면 "OK"

$ python3 scripts/verify_deck.py deck.html --shots out/
→ 슬라이드별 PNG + 컨택트시트
