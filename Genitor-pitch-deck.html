손대지 않고, 더 멋지게
기존 이미지를 다시 디자인하고, 슬라이드 배경을 한 줄로 생성합니다.
🪄
AI 디자인 향상
글자·요소 위치는 그대로 유지한 채 타이포·여백·색 조화만 끌어올립니다. 한글·한자·일본어도 깨지지 않게 보존.
🌌
AI 배경 생성
주제 한 줄과 스타일을 고르면 텍스트 가독성을 해치지 않는 저대비 배경을 만들어 슬라이드에 깔아줍니다.
당신의 슬라이드는 서버로 가지 않는다
Genitor는 자체 백엔드가 없습니다. AI 호출은 브라우저에서 직접, 당신의 키로.
🚫
중개 서버 없음
슬라이드 데이터를 거쳐가는 서버가 없습니다. 브라우저 ↔ AI 제공자 직접 통신.
💻
로컬 LLM (Ollama)
OpenAI 호환 엔드포인트로 전환하면 텍스트 AI를 완전 오프라인으로.
🏛️
보안 조직에 적합
금융·공공·의료 등 외부 업로드가 금지된 환경에서도 AI 슬라이드 제작.
소리에 반응하는 슬라이드
고유 기능
mp3를 올리면 실시간 주파수 스펙트럼 요소가 됩니다. 발표 중 음악에 맞춰 살아 움직입니다.
💡 발표·제품 데모·음악 수업에서 정적인 슬라이드를 동적 무대로 바꿉니다.
다이어그램도, 아키텍처도
도형을 잇는 커넥터 + 공식 AWS 아이콘 46종. 개발자·솔루션 아키텍트를 위한 모드.
사용자
API Gateway
Lambda
DynamoDB
드래그&드롭 AWS 아이콘 · 그룹 컨테이너 · 가장자리 스냅
💡 별도 다이어그램 툴(draw.io 등) 없이, 발표 자료 안에서 바로 아키텍처를 그립니다.
발표까지 끝내는 한 곳
만든 자료를 다른 도구로 옮기지 않고, Genitor 안에서 바로 발표합니다.
🖊️
발표 중 펜 주석
펜·형광펜·지우개로 실시간 강조. 마우스와 터치 모두 지원.
🔊
TTS 나레이션
발표자 노트를 음성으로. 슬라이드마다 자동 재생되는 셀프 러닝 자료로.
✨
등장 애니메이션
클릭·자동·연쇄 트리거로 요소 등장. 페이지 진입 즉시 재생도 지원.
갇히지 않는 포맷
기존 워크플로와 AI 도구 사이를 자유롭게 오갑니다.
📤
고품질 PPTX 내보내기
폰트 임베딩·그라데이션·표까지. PowerPoint에서 그대로 열립니다.
📥
HTML 가져오기
웹 슬라이드·클립보드 HTML을 붙여넣으면 편집 가능한 요소로 변환.
🤝
Claude 핸드오프
Claude로 초안 덱을 생성 → Genitor에 붙여넣어 무손실 임포트 → 이어서 편집·발표. 이 자료도 그렇게 만들어졌습니다.
누가, 어떻게 쓰는가
AI 비주얼·프라이버시·발표 경험이 필요한 모든 사람.
🚀
스타트업 IR · 세일즈
투자 피치덱·세일즈덱을 AI 비주얼로 빠르게. 디자이너 없이도 일관된 톤.
🎓
교육자 · 강사
TTS 나레이션 + 펜 주석으로 온라인 강의·셀프 러닝 자료 제작.
📣
마케터 · 크리에이터
AI 이미지·오디오 비주얼라이저로 SNS·이벤트용 동적 콘텐츠를.
🛠️
개발자 · 솔루션 아키텍트
AWS 다이어그램·아키텍처 설명을 발표 자료 안에서 바로. 보안 환경엔 로컬 LLM.
